Getting Started

Rogue Client is a free, open-source Minecraft launcher built by Syndicate Software. It's designed to be lightweight, modern, and focused on performance, with built-in mods so you don't have to install and manage them yourself.

Rogue Client currently supports Minecraft 1.14+ and 1.8.9 with OptiFine. Check the Discord for updates on future version support.

Rogue Client is available for Windows (installer .exe) and Linux (universal AppImage, works on any distro, no install required). You can grab both from the download section.

Yes, Rogue Client is completely free to download and use. If you'd like to support development, optional donations are appreciated but never required, no feature is ever locked behind a paywall.

Accounts & Login

Rogue Client supports two login methods:

  • Microsoft Account, sign in with the Microsoft account tied to your official, purchased copy of Minecraft.
  • Ely.by, a third-party authentication service you can create a separate account with.

They are not the same thing. Ely.by is a legitimate, independent authentication service with its own account system, skins, and servers built to support it, it's a real login provider, not a way to bypass Mojang's ownership check.

A "cracked" account, by contrast, refers to bypassing Minecraft's official login entirely to play without owning the game. Rogue Client does not support or provide cracked/offline login, you need either a genuine Microsoft-linked Minecraft account or an Ely.by account to play.

To log in with Microsoft, yes, you need a genuine copy of Minecraft. If you use Ely.by instead, you'll need an Ely.by account, which has its own separate registration and is not linked to Mojang/Microsoft ownership.

No, Rogue Client will never support cracked/offline Minecraft, doing so would violate Microsoft's Minecraft EULA.

Features & Mods

Rogue Client ships with mods developed by Popcorn covering two main areas:

  • Performance mods, optimizations aimed at boosting FPS and reducing stutter/lag.
  • PvP mods, combat-focused tweaks and quality-of-life features for competitive play.

These are integrated directly into the client, so there's no separate mod installation or Forge/Fabric setup needed.

Rogue Client itself isn't customizable at the client level, but you can add your own mods on top as long as they're compatible with Rogue Client's built-in mods.

No, Rogue Client will never add standalone mods.

No, Rogue Client will not get you banned.

Troubleshooting

On Linux, make sure the AppImage has execute permissions (right-click → Properties → Permissions, or run chmod +x on it from a terminal). On Windows, make sure you ran the installer fully and that your antivirus hasn't quarantined any files.

If it still won't start, join the Discord and post details in the support channel.

Bug reports and support requests go through Discord, not the business email, that inbox is for business inquiries only and isn't monitored for support.

Open a ticket in the Discord and the team will take a look.

Project & Source Code

The project originally started as Rocket Client. Partway through, we found out the name was already claimed by another Minecraft client. That dev had put real money into their project, and it felt wrong to keep the name and cause confusion or step on what they'd built, so we changed it to Rogue Client instead.

It's a bit of a shame, honestly we wanted to name our client Roketto, Japanese for "rocket," as an april fools.

Not exactly. Rogue Client is not open source, but the code is publicly viewable on the GitHub repo for transparency purposes. Check the license in the repo for details on what you can and can't do with it.
